# 智能家居 Demo 项目需求

版本：v1.0  
日期：2026-10-24  
状态：根据本轮审核意见形成的需求文档；功能尚未开发或实物验收。

## 1. 项目目标与开发方式

使用一套 STM32 智能家居终端，演示温湿度采集、灯光调节、风扇调速、按键控制、离线语音、OLED 显示，以及通过 OneNET 与 Android App 完成远程控制和状态同步。

- 使用 STM32CubeMX 配置引脚、时钟及外设，保存 `.ioc` 并生成 HAL 初始化工程。
- 使用 Keil5 编写、编译、下载和调试程序，最终工程须能直接在 Keil5 中打开使用。
- 驱动和业务代码与生成代码合理分离，CubeMX 再次生成时保留用户代码。
- 用户深度参与配置、实现和实物调试；AI 按已明确的任务范围协作。
- Git 工作方式遵循根目录 `AGENTS.md`：同一仓库、模块独立克隆与分支、验证后合并到 `develop`。
- 本阶段形成需求及引脚规划，下一阶段再确定模块边界、开发顺序和业务逻辑实现，不在本文中安排开发任务。

本项目按单人操作单台设备、供电接线正确且网络可用的演示环境定义。安全专项、复杂故障恢复及产品化能力不纳入本版；正常通信解析、按键消抖和数据校验属于实现基本功能的必要内容。

## 2. 硬件范围

硬件依据为仓库根目录的 [项目原理图](../SCH_Schematic1_2026-10-24.pdf)，新增 DHT11 连接详见 [引脚规划与检查](02_引脚规划与检查.md)。

| 模块 | 确定的硬件 | 用途 |
| --- | --- | --- |
| 主控 | STM32F103C8T6 主控板 | 采集、控制、通信及统一设备状态 |
| 温湿度 | DHT11 | 采集实际温湿度；原理图待补充 PB0 数据线 |
| 显示 | 0.96 寸 I²C OLED | 本地显示环境数据、控制状态和联网状态 |
| 按键 | SW1、SW2、SW3 | 本地灯光开关、风扇启停及档位切换 |
| 语音 | SU-03T | 固定词条离线识别，通过串口发送控制指令 |
| 联网 | ESP-01S | 使用 AT 固件连接 Wi-Fi 和 OneNET |
| 灯光 | 外接普通 LED | 开关与亮度演示 |
| 风扇 | HS-F04P 驱动板及风扇 | 固定方向启停、低中高三档 |

麦克风、扬声器、电源、串口工具及下载器作为配套器件。U4 的 `ESP32-01s` 标注按用户确认解释为 ESP-01S，后续更新原理图标注；U5 型号确定为 SU-03T，H2 外接驱动确定为 HS-F04P。

OLED 的控制芯片、分辨率和 I²C 地址尚未确定，模块设计时依据实物资料选择驱动。本文不默认具体显示芯片或固定地址。

## 3. 功能需求

| 编号 | 功能 | 要求 |
| --- | --- | --- |
| R01 | 工程运行 | CubeMX 配置、Keil5 工程及源码完整，可编译、下载并在主控板运行。 |
| R02 | 温湿度 | 上电约 2 秒后开始采集，此后每 3 秒读取一次，OLED 和 App 显示真实数据及单位；未取得有效读数时显示 `--`。 |
| R03 | 灯光 | 支持开关及 1～100 的整数亮度设置；演示 30、60、100 时存在可观察的亮度差别。 |
| R04 | 风扇 | 支持启停及低、中、高三档；每档可从停止状态启动，运行中可切档，实物速度有区别；固定转向。 |
| R05 | 按键 | SW1 切换灯光开关，SW2 切换风扇启停，SW3 按低→中→高→低循环选择档位；一次按下产生一次操作。 |
| R06 | 语音 | 完成第 4 节规定的唤醒词和 11 条控制词；语音模块发指令，STM32 执行控制。 |
| R07 | OLED | 固定状态页显示温湿度、灯光开关与亮度设置、风扇开关与档位设置、联网状态；显示不依赖 App 是否打开。 |
| R08 | 联网 | 使用预先配置的 Wi-Fi 和平台参数，上电连接 OneNET，完成设备状态上报与控制接收。 |
| R09 | Android App | 使用 uni-app，交付可独立安装启动的 APK；固定控制一台设备。 |
| R10 | 状态同步 | 按键、语音和 App 操作同一份设备状态，OLED 和 App 按设备最新状态更新。 |
| R11 | 日志 | 通过调试串口输出启动、采集、联网、控制及当前状态，便于联调；不建设日志存储系统。 |

按键本版只使用单击。调光通过语音及 App 完成；全部关闭通过语音及 App 执行。按键和语音的本地控制、温湿度采集及 OLED 显示不以云端连接成功为前提。

## 4. 语音与界面

唤醒词使用“你好小智”。每条控制词允许先重新唤醒，不要求连续对话。

| 控制词 | 动作 |
| --- | --- |
| 打开灯光 / 关闭灯光 | 设置灯光开关 |
| 灯光低亮度 / 灯光中亮度 / 灯光高亮度 | 分别设置亮度 30 / 60 / 100 |
| 打开风扇 / 关闭风扇 | 设置风扇开关 |
| 风扇低档 / 风扇中档 / 风扇高档 | 分别设置档位 1 / 2 / 3 |
| 全部关闭 | 同时关闭灯光和风扇 |

语音串口帧和词条工程在模块设计时统一。交付对应 SU-03T 工程配置及可烧录固件；无需手机录音、温湿度动态播报或执行结果播报。

OLED 使用简洁固定页面，布局按实际分辨率确定。联网信息至少区分连接中、云端已连接和未连接；不能把仅连接 Wi-Fi 显示为云端已连接。关灯、停扇时仍显示保存的亮度和档位设置。

App 使用一个中文控制首页，包含设备名、温湿度、灯光开关与亮度滑杆、风扇开关与三档选择、全部关闭、手动刷新及最近读取时间。提供简单项目说明入口，列出语音词条。

- 亮度滑杆松手后提交一次；拖动过程中显示待提交设置。
- App 根据设备上报结果显示控制状态，提交中提供简单等待提示。
- 首页可见时自动刷新；退出前台停止轮询，重新进入时读取设备现状。
- 不设置配网、设备搜索、账户或多设备管理页面。

## 5. 统一操作规则

| 编号 | 规则 |
| --- | --- |
| B01 | STM32 保存唯一设备状态，按键、语音和 App 通过同一控制入口修改。 |
| B02 | 指令按 STM32 接收并处理的顺序生效，不设置语音优先保护时间。 |
| B03 | 每次主控上电，灯光和风扇关闭，亮度设为 60，风扇档位设为中档。 |
| B04 | 关闭时修改亮度或档位只保存设置，不开启负载；再次开启使用保存值。SW3 同样遵循此规则。 |
| B05 | 全部关闭只改变两个开关，保留亮度和档位。 |
| B06 | 设置只保存在本次运行中，断电或主控重启恢复初始值。 |
| B07 | App 重开或返回前台只读取设备当前状态，不发送默认开关、亮度或档位。 |
| B08 | 温湿度用于展示，不自动启动风扇或切换档位。 |
| B09 | 语音和 App 的“打开/关闭”使用明确设置；重复打开仍保持打开。按键的切换动作由 STM32 根据当前状态计算。 |
| B10 | 仅修改命令携带的设置项，其余设置保持不变。 |

## 6. 云端数据范围

使用 OneNET 一个产品、一台演示设备。设备通过 ESP-01S 的 MQTT 能力上报及接收控制；App 使用 OneNET 应用接口读取和设置属性。具体报文、接入地址及 AT 指令在通信模块设计时核对，不在需求阶段冻结实现。

| 属性 | 类型 | 读写 | 含义 |
| --- | --- | --- | --- |
| `temperature_c` | 数值 | 读取 | 最近一次有效温度，单位 ℃ |
| `humidity_pct` | 数值 | 读取 | 最近一次有效相对湿度，单位 %RH |
| `led_on` | 布尔值 | 读取、设置 | 灯光开关 |
| `led_brightness` | 整数 1～100 | 读取、设置 | 保存的亮度设置 |
| `fan_on` | 布尔值 | 读取、设置 | 风扇开关 |
| `fan_level` | 整数 1～3 | 读取、设置 | 低、中、高档位 |

正常连接后上报当前状态；每次有效采样后上报；控制状态变化后及时触发上报。首次没有有效温湿度时先上报控制属性，不上传虚构温湿度。

联网参数预先配置，不开发配置界面。沿用既有产品或新建演示设备的具体选择，在云端模块实施前确认；本文不授权修改线上设备。

## 7. 演示目标与验收

下表是设计目标，均尚未实测；按已配置且网络正常的演示环境验收。

| 项目 | 目标 |
| --- | --- |
| 采集周期 | 每 3 秒读取一次 DHT11 |
| OLED 控制状态更新 | STM32 执行控制后 1 秒内更新 |
| App 控制 | 提交后 3 秒内观察到对应负载响应 |
| App 状态同步 | 控制变化或采样完成后 5 秒内反映到 App |
| App 刷新 | 初始候选每 2 秒一次；核对平台额度后确定，调整时同步更新相关时延目标 |
| 演示方式 | 在实际 Android 手机和完整实物装置上完成约 3～5 分钟演示 |

验收场景包括：Keil5 编译下载与启动、温湿度在 OLED/App 上更新、三颗按键操作、11 条语音控制、App 调光和风扇三档、三种入口交替控制与状态一致、全部关闭、关闭时修改设置后再开启、App 重开读取现状、主控重启恢复初始值。

编译检查和模拟可辅助调试；功能完成以实际传感器读数、负载动作和手机端闭环记录为依据。

## 8. 交付与边界

交付 CubeMX `.ioc`、Keil5 工程及源码、可烧录固件、SU-03T 配置和固件、ESP-01S 工作固件及参数说明、OLED 适配信息、OneNET 配置说明、App 源码及 APK、最终接线表和演示步骤。

本版不安排安全专项、复杂故障恢复、异常压力测试、长期运行指标、登录及权限、多设备管理、历史曲线、自建后台、自动温控、场景联动、定时任务、断电记忆、OTA、iOS 或应用商店上架。

引脚资源检查通过不等于整板电气连接或实物功能已验收。用户已在 R01 阶段确认主控板外部晶振为 8 MHz；当前待补齐事项是 DHT11 原理图连接、HS-F04P 接口适配、OLED 实物信息、主控板时钟运行验证及 SWD 接口、风扇调速参数；具体记录见配套引脚文档。
